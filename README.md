## Selected Projects

### 🔎 [ClaimTrace](https://github.com/himanq/ClaimTrace)
A local-first research tool for tracing claims to potentially supporting, challenging, or contextual evidence. Includes lexical retrieval, optional dense retrieval, evidence tracking, and a small retrieval-evaluation workflow.

**Focus:** Python · Information Retrieval · RAG concepts

### 🧭 [HireSense](https://github.com/himanq/HireSense)
A browser-based resume review toolkit that checks common resume signals, compares text with a job description, and generates editable reports and templates. It uses transparent JavaScript heuristics—not an official ATS score or an interview predictor.

**Focus:** JavaScript · HTML · CSS · Client-side tooling

### 🤖 [AI Resume Screening](https://github.com/himanq/AI_resume)
A Streamlit and scikit-learn demo that explores classification using structured, resume-like features. The included dataset is for demonstration and should not be treated as real-world hiring evidence.

**Focus:** Python · scikit-learn · Model evaluation

### 🧠 [DSA Revision](https://github.com/himanq/DSA-RE)
A growing collection of coding-practice solutions organized to support revision of problem-solving patterns.

**Focus:** Java · Data Structures & Algorithms
